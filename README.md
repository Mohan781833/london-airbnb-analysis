# London Airbnb Analysis

## Problem
 London short-let property managers operate in a highly saturated market where listing performance varies dramatically by borough, property type, and pricing strategy, making it difficult to know which properties to acquire or how to price them.
 ## Stakeholder
The stakeholder is the Head of Portfolio at a London property management company, who needs evidence on which listing characteristics drive higher occupancy, revenue, and guest satisfaction.
 ## Data source
Inside Airbnb (insideairbnb.com) — London snapshot, June 2026.
92,638 listings, 2.24M reviews. Raw data not committed due to size; the pipeline notebook reproduces it.

## Folder structure
- /notebooks — 01_pipeline (loading and verification), 02_cleaning (audit, decisions, features)
- /data — analysis-ready CSV
- /sql, /dashboard — added in later phases

## How to run
1. Download listings.csv.gz and reviews.csv.gz from Inside Airbnb into data/raw/
2. pip install -r requirements.txt
3. Run notebooks in order (Restart Kernel and Run All)
